# 角色一致性与自然表演

本规则与 `motion-naturalness.md` 共同约束角色跨分镜身份和动作。角色身份一致性优先于单张画面的美观程度；人物默认稳定，只有明确剧情事件才产生动作。

## 身份锁定

每个主要角色必须先有固定 Character Reference。后续分镜优先使用该参考建立身份，再按剧情重新设计姿势、表情、视线、动作、景别和机位。参考图锁定：

- 脸型、五官比例、眼睛形状与瞳色、鼻口特征、肤色
- 发色、发型结构、刘海形状、头发长度、标志性发饰
- 体型比例、服装款式与颜色、鞋子和主要配饰

每个角色至少记录 3–5 个视觉识别锚点。镜头切换不应重新设计角色；如果身份锚点明显漂移，该镜头视为失败并返工。姿势、表情、嘴型、视线、头部角度、手势、动作、景别和机位可以变化。

## 事件驱动表演

添加动作前先回答“角色为什么现在要动？”触发原因只能来自台词、情绪变化、新信息、互动、观察物体、明确行为或对上一句台词的反应。没有触发原因的动作删除。

动作使用以下节奏：

```text
稳定 → 准备 → 执行动作 → 短暂停顿 → 回到稳定
```

一次只突出一个主要动作。说话时可以有小幅嘴型、一次轻微头部动作、对应的视线和必要的单一手势；较长台词最多安排少量自然眨眼。禁止持续漂浮、左右摇摆、机械呼吸、固定频率点头/眨眼，以及让头、身体、手、眼睛同时不停运动。

## 嘴型与眨眼

嘴型只在实际配音区间变化；短暂停顿和句子结束后立即回到稳定闭嘴状态。不要用固定的闭嘴→张嘴循环代替对白节奏。

眨眼是偶发事件，不是循环动画。短反应镜头可以不眨眼；长镜头根据表演需要人工安排少量眨眼。每个镜头记录主角眨眼时间，视觉复核应能数出完整的睁眼→闭眼→睁眼事件。

## 倾听与情绪

倾听者保持静止，只选择一个主要反应：视线转向、轻微抬头、一次眨眼、表情变化、轻微转头或短暂沉默。情绪变化优先用表情变化→停顿→CUT 表达；大幅姿势变化应生成新的漫画分镜，而不是移动整个人物图层。

## Remotion 前的动作记录

每个镜头进入 Remotion 前必须填写：

```text
角色
当前状态
动作触发原因
主要动作
次要动作
动作开始时间
动作持续时间
静止时间
眨眼时间
嘴型区间
表情变化
台词
CUT 时间
```

缺少动作触发原因时不进入渲染。Remotion 只负责嘴型切换、眨眼、一次性头部/眼神动作、简单手势、字幕、配音、音效和 CUT；禁止默认加入整个人物缩放、旋转、平移、漂浮、摆动、机械呼吸或周期动画。

## 输出前 QC

逐镜检查：

1. 角色是否与上一镜保持同一张脸、发型、服装、比例和识别锚点？
2. 动作是否能指向明确剧情事件？
3. 嘴型是否只在发声时变化，停顿后是否稳定？
4. 眨眼是否过于规律，是否能数清事件次数？
5. 动作结束后是否真正停住？
6. 倾听者是否有合理但克制的反应？
7. 删除某个动作是否完全不影响剧情？若是，删除它。

自动校验不能证明像素级身份一致、五官漂移、发根接缝或表演自然度；必须查看首帧、关键帧、中间帧和末帧接触表。不要通过修改标签或增加 `repetition_exception` 来掩盖画面问题。
