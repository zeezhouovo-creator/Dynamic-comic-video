# 漫画经济画面档位

这是动态漫画的默认生图方向之一：优先保证角色身份、动作可读性和跨镜一致性，不把计算量和时间花在电影级背景细节上。

## 生成原则

- 以用户提供的角色参考锁定脸型、发型、服装、比例和辨识点；参考图的姿势、表情和构图不直接复制。
- 背景只保留能说明地点、空间关系和叙事重点的物件，使用清晰轮廓、有限色块和适度留白。
- 线条、表情和动作优先于复杂材质；手机、书、桌面等道具只画到能支撑剧情的程度。
- 每个镜头仍然生成新的姿势、表情、景别和构图，不能用一张精致立绘反复贴图。
- “类似轻松的中国校园搞笑条漫”只能作为抽象表现方向；不得复制《阿衰》或其他作品的具体角色、台词、构图和独特画风。

## 何时切换档位

在 `production_brief.json` 中设置：

```json
{
  "render_profile": "comic-economy"
}
```

`comic-economy` 适合连续分镜和批量预览；`standard` 用于需要更多背景信息的项目；`high-detail` 只有用户明确要求精细插画时才使用。档位只控制生图的细节预算，不改变题材、地域、时代或叙事目的。
