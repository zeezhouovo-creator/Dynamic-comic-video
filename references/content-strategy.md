# 短视频内容策划层

动态漫画先要是一条成立的视频，再是一组好看的镜头。内容策划层负责回答“给谁看、为什么现在看、看完记住什么、下一步做什么”；角色、分镜和动画只服务这些答案。

## brief 中的内容策略

需要面向平台发布、教育解释、观点表达、品牌传播或连续剧情时，在 `production_brief.json` 增加 `content_strategy`。它是可选模块；纯视觉测试或用户明确不需要平台策略时可以省略。

```json
{
  "content_strategy": {
    "audience": "第一次接触这个主题的普通观众",
    "platform": "douyin",
    "goal": "education",
    "hook": "你以为记住一个知识点靠的是重复，其实关键在第一次理解",
    "core_promise": "用一个生活场景解释记忆形成的关键转折",
    "takeaway": "观众看完能复述一个明确判断和一个可执行动作",
    "cta": "把这个方法用在今天要记的内容上"
  }
}
```

`hook` 不是标题复述，而是前 1–2 秒内必须出现的疑问、冲突、结果或反常识。`core_promise` 只能有一个，避免一条短片同时讲多个主题。`takeaway` 应能用一句话复述；`cta` 只在确实需要观众行动时填写，不为了完整而强加。

## 30–60 秒的内容节奏

按实际台词和素材调整，不按固定秒数硬套，但应保留以下叙事功能：

1. **钩子**：马上给出冲突、结果或未解问题，禁止先放无信息的片头。
2. **建立**：用一个可识别的人物、地点或具体行为说明问题是谁的。
3. **推进**：每个镜头至少带来一个信息、动作或关系变化；没有变化就合并镜头。
4. **转折与兑现**：回答钩子提出的问题，或让人物做出有因果的选择；不能只靠字幕宣布结论。
5. **收束**：留下情绪余韵、明确结论或可执行动作。需要 CTA 时保持一句话。

短片通常控制在 3–7 个独立分镜。单镜只承担一个主要动作、信息或反应；对白过长时按语义和反应拆镜，而不是把整段台词塞进一个画面。复杂背景、特效和知识卡不能替代内容推进。

## 内容审阅清单

- 前两秒能否说清冲突、结果或问题？
- 每个镜头是否改变了信息、动作、关系或情绪中的至少一项？
- 是否只有一个核心承诺，且在结尾兑现？
- 台词是否口语化、可听懂、能在当前时长内自然说完？
- 是否给了观众必要的反应停顿，而不是连续解释？
- 结尾是故事完成、观点落地还是行动提示，是否与目标一致？
- 删除任一镜头后，内容是否变得更清楚；若没有，应合并或删除？

自动校验只能检查字段、时间和引用。钩子是否有吸引力、结论是否可信、笑点是否成立和情绪是否有效，必须通过脚本朗读与视频复看判断。
