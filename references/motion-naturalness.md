# 人物动作自然度规则

`motion_plan` 0.3 中人物默认静止。动作必须由台词、听到的信息、自然停顿、情绪变化或明确行为触发，完成后回到稳定状态。

用 `acting.events` 描述一个事件的 `start_frame → peak_frame → settle_frame → end_frame`。动作应有准备、动作、停顿/回稳节奏；没有事件的部件保持稳定。一次只突出一个主要动作，其他部件不同时循环运动。

禁止持续上下浮动、左右摇摆、缩放、机械呼吸和固定频率重复眨眼/点头；禁止用 sin/cos 或等价循环驱动整个人物。复杂动作优先切换到下一张漫画分镜。听者反应必须由信息触发并记录在 `direction.listening_reactions`。

自动校验会检查事件阶段顺序、重叠事件、重复事件和明显周期关键帧。视觉验收仍需查看准备、峰值、回稳和末帧，确认动作有因果、只突出一个重点、其余部位稳定，没有匀速往复或机械循环。
