# 可选收束卡

知识卡、总结卡和行动号召卡都是可选的收束镜头，不是动态漫画的默认结尾。是否使用由用户提出并决定，Skill 不根据题材自行追加。

用户决定需要解释、复盘、知识点落地或下一步行动时，才在 `production_brief.json` 中开启：

```json
{
  "outro_card": {
    "enabled": true,
    "kind": "knowledge",
    "rationale": "本话的笑点需要落到信源可信度定义",
    "shot_id": "shot_009",
    "duration_frames": 120
  }
}
```

不开启时可省略整个字段，或设置 `enabled: false`。纯故事、品牌情绪片和已经完成表达的短片应直接结束，不为了“完整”追加知识卡。

开启后，卡片必须作为独立漫画镜头加入分镜和时间轴，使用直接 CUT；不要把大段解释压在人物对白上，也不要用卡片替代角色反应。卡片文字只能来自 brief、故事或用户明确提供的知识点，不能擅自补充事实。默认保持静止、干净、短暂；视觉语言继承项目设定，可使用纸片拼贴预设，但不改变内容主题。
