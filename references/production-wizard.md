# 动态漫画制作向导

这是 Skill 的用户入口层。用户只需提供创作意图，Skill 负责把意图转换成可执行的动态漫画方案；不要要求用户理解角色一致性、事件动作、时间轴、CUT 或 Remotion。

## 启动判断

先检查当前对话和素材，锁定已经明确的剧情、素材来源、角色设定、视觉风格、视频比例和配音需求。已知信息不重复询问，只补问当前阶段真正缺失的信息。

如果素材来源尚未明确，只问一个入口问题：

```text
这次准备从哪里开始？
A. 我已经有独立分镜图片
B. 我已经有角色设定，需要生成新的分镜
C. 我没有现成素材，从剧情开始
```

多张明显属于独立分镜的图片自动进入 A；角色立绘、三视图或角色设定图优先进入 B。完整四格或多格漫画不作为默认入口，只有用户明确要求时才识别格子并评估是否能直接动态化。若已有分镜足够，进入动态设计，不重新生成整组素材；只对缺失或不合格的镜头局部补充。

## 三种入口

### A：已有独立分镜

按阅读或文件顺序整理镜头，分析场景、人物、说话者、关系、台词、情绪、动作和镜头功能。检查角色一致性、场景连续性、重复构图和反应镜头缺口。保持可用素材，只修改有问题的镜头。

### B：已有角色设定

先建立 Character Reference，记录脸型、五官、发型、发色、瞳色、服装、体型、配饰和主要配色等识别锚点。随后获取或读取剧情，按剧情生成独立分镜；每个分镜继承 Character Reference，角色一致性优先于单张美观。

### C：从剧情开始

先获取故事或主题。只有主题时，协助整理成短剧情；剧情确定后依次生成角色、确认角色、确定视觉风格、设计分镜、生成素材，再进入动态化。角色尚未确定时不批量生成正式分镜。

## 只问必要信息

需要生成新视觉素材时才询问画风。提供日系校园动漫、Q 版搞笑漫画、国漫、韩漫、黑白漫画、美式漫画、轻小说插画和自定义参考图等高层选项；参考图优先于文字标签，并分析线条、比例、五官、上色、光影、背景复杂度和漫画符号。已有分镜不重复询问画风。

比例未明确且会影响构图时才询问：9:16、16:9、1:1、4:3 或自定义。抖音、TikTok、Shorts 默认建议 9:16；若素材比例与目标比例冲突，提前提示。动态模式只提供轻微动态、标准动态、夸张搞笑三个高层选择，内部帧数和动作参数自动决定。

正式合成前检查是否已有配音。已有配音直接建立时间轴；没有配音才询问是否生成，并只收集角色声音、语速、情绪、背景音乐和环境音等高层偏好。嘴型、字幕、动作节点、反应停顿、CUT、重点词和音效由系统根据剧情和配音自动决定。

## 计划确认与执行

信息足够后先给出简短制作计划，包含素材入口、画风、比例、动态模式、预计镜头数和声音方案。用户确认后才进入完整制作。内部规则顺序固定为：

```text
角色一致性
→ 分镜连续性
→ 事件驱动自然动作
→ 音频驱动时间轴
→ 漫画演出与视听反馈
→ Remotion 合成
```

后面的模块不得破坏前面已经确定的规则。字幕不得遮挡关键表情；特效不得破坏角色身份；Remotion 不得用整图缩放替代人物动作。

## 局部失败处理

先归类问题：角色、分镜、动作、字幕、声音、节奏或特效。只重做对应模块：脸变了就重做该镜角色；动作机械就改动作事件；字幕太快就改时间轴；CUT 太慢就改镜头时长；特效过密就删减特效。不要因为一个局部问题重做全片。

## 预览与反馈

正式输出前优先生成前 10–20 秒或 3–5 个代表镜头，检查角色一致性、动作自然度、字幕同步、配音节奏、CUT 节奏和漫画演出。用户提出修改时只修改对应模块，保留已经确认的剧情、角色、画风、背景和字幕样式。

Skill 的体验应像动态漫画制作助手：先判断、少提问、自动做技术决策、先给预览，再根据反馈做局部修改。用户不需要填写帧数、计算字幕时间或手动安排眨眼。
