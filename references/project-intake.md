# 新项目启动引导

新项目开始时先问：**“这次你希望使用已有素材，还是直接生成新的漫画素材？”**一次只询问当前必要的信息。

- **已有完整漫画/四格/多格**：识别真实格子边界，按阅读顺序裁成 `panel_01`、`panel_02`……，保留人物、服装、画风、场景、构图、剧情和关系。一个格子有多个叙事重点时，可拆成多个独立静态镜头，但禁止持续放大、缩小或平移原图。
- **已有单张分镜**：按剧情顺序分析说话者、倾听者、情绪、动作、视线、字幕时机和 CUT；不重画已确认分镜，只在必要时拆局部层。
- **已有角色设定**：先锁发型、发色、五官、脸型、体型、服装、配饰和画风，再按剧情生成新姿势、表情、视线、景别、机位和构图。
- **从零生成**：故事/主题 → 角色设计 → 用户确认角色 → 画风确认 → 分镜设计 → 素材生成 → 分镜裁切 → 动态设计 → 配音/字幕/音效 → Remotion 合成。角色和画风未确认前，不批量生成正式分镜。

生成新素材时再确认视觉风格和最终比例（9:16、16:9、4:3、1:1 或自定义）。参考图优先分析线条、上色、比例、五官、光影、背景复杂度和漫画表现。每镜写 `source_panel`，使来源漫画格、拆镜理由与独立构图可追溯。
