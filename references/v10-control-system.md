# V1.0 总控与恢复规则

本文件只负责入口分流、恢复、阶段衔接和返工。创作约束与模块入口见 [SKILL.md](../SKILL.md)，具体制作规则由该模块维护；总控不另建动画或数据协议。

## 先识别任务和现有证据

读取用户本次目标、已有选择和指定目录。新项目按 [制作向导](production-wizard.md) 补齐必要信息；继续制作先按 [状态机](project-state.md) 运行只读 `inspect`，再核对当前文件、历史确认和待处理反馈。只处理用户请求的交付范围。

`project_state.json` 是流程记录，不是质量证明。inspect 的阶段是建议：文件存在不代表内容有效，旧报告或旧 MP4 不代表当前修改已验收。不要覆盖已有状态来重新初始化；不要仅凭文件存在跳过校验或将项目设为 FINAL。

| 已有输入 | 下一步 |
| --- | --- |
| 独立分镜 | 按顺序分析身份、空间、台词和动作需求，依下节判断复用，再补缺失镜头或图层 |
| 角色设定 | 提取身份锚点，复用合格 reference，读取剧情后设计分镜 |
| 剧情或文案 | 保留原文事实与因果，提取 beats，按需要建立角色和分镜 |
| 只有想法 | 形成最小剧情方案；只问会改变题材、事实边界或阻止下一步的缺项 |
| 已有项目及反馈 | 定位受影响镜头、数据和依赖，按返工表处理 |

## 已有分镜的复用边界

用户明确要求“把这些分镜做成动态视频”或明确指定复用时，视为已授权使用这些图作为最终镜头候选；核对尺寸、身份、空间和分层可行性后保留合格素材，只修缺项。无需重复询问相同授权。

用户只将图片提供为身份、画风或构图参考时，不自动当作最终 master；按剧情新绘。用途确实不明且会决定重绘成本时，只问素材用途，不先批量重画。完整多格漫画只在用户要求时拆格，并检查裁切后是否仍能完成所需表演。

用户提供参考视频时，提取分镜密度、景别变化、CUT 节奏、动作幅度、反应停顿、字幕逻辑和声音层级等表现规律；不把参考作品的人物、剧情、台词或独特资产移入新故事。

## 阶段与数据衔接

执行层继续使用四份制作合同和现有 Remotion 模板，按 [契约说明](contracts.md) 写字段。总控所称“Scene”是编排概念，不能新建 camelCase 合同或把空间场景 `scenes` 与时间镜头 `shots` 混为一谈。

- 镜头次序、角色、场景、对白和 CUT 原因来自 storyboard 的 shots/direction。
- 镜头时长、字幕、speech intervals、动作、表情、眨眼及 CUT 使用该镜 motion timeline 的现有 schema 字段。
- 漫画效果与声音使用 `visual_events` / `sound_events`，不在组件中维护第二套时间轴。
- ANIMATION 可以先设计动作意图；最终帧数需等实际配音及 AUDIO 阶段确定后回填。状态名顺序不是提前锁死音频时间的理由。

状态转换及命令由 [项目状态机](project-state.md) 维护。已知用户选择与授权持续有效，普通技术决策由 Agent 完成；只在关键输入缺失或确需用户验收时等待。

## 预览与验收

优先预览前 10–20 秒或 3–5 个代表镜头；短片可全长预览。只覆盖项目实际具备的内容：有对白才检查说话/嘴型，有动作才检查接触与遮挡，有特效才选其代表，有多镜才检查 CUT。不得为满足预览清单添加对白、人物或特效。

`preview.py` 默认渲染传入项目全长；需要局部预览时使用 `--shot <shot_id>`，脚本会调用现有的 shot 编译/prepare 路径，将该镜头时间轴归零并输出 `preview_<shot_id>.mp4`。每次预览会生成项目内 `visual-review/` 的首/中/末帧和 `visual_review.json`。不裁改原项目、不手工同步时间轴，也不使用不存在的 CLI 参数。

运行 [质量闸门](quality-gate.md)，修复 Critical/Major 后渲染；视觉与听觉问题仍须实际查看、试听。自动修复仅限脚本支持的安全元数据，不能修复角色漂移、缺图或艺术质量。依据实际观察填写复核字段。

进入 FINAL 需要用户对当前预览的确认，不能从 inspect 推断。已有确认只适用于对应版本；后续修改重新检查受影响部分。预览完成后保留项目及依赖文件以便恢复，交付状态如实说明。

## 用户反馈与最小返工

`route-feedback` 是关键词建议，不是完整诊断；一句话含多个问题时逐项定位，不只处理脚本返回的第一个模块。

| 反馈 | 优先检查 | 连带复核 |
| --- | --- | --- |
| 人物不像同一个人 | 对应角色锚点、该镜 master/图层 | 替换图层后的对齐、遮挡和动作 |
| 动作怪、一直晃 | 动作事件、关节/接触、静止段 | 相关关键帧和中间帧 |
| 像 PPT | 分镜的信息变化、反应、人物表演 | 新增/调整镜头的连续性与 CUT |
| 嘴型不对、字幕太快 | 实际音频、字幕和 speech intervals | 同段动作、停顿和镜头时长 |
| 字幕抢眼或遮脸 | 字幕样式与位置 | 有关镜头的可读性，不自动重做配音 |
| 节奏赶或拖 | 镜头时长、反应停顿和 CUT | 后续 start_frame、总帧数及统一时间轴 |
| 特效/音效太多 | 对应 visual_events / sound_events | 该事件与对白的层级 |
| 背景像换地方 | 场景空间记录、该镜机位与 master | 相邻镜头的连续性和图层 |

保留已确认且不受影响的素材。最小返工包含必要的依赖更新：改镜头时长需要重算后续起点，换 master 需要复核关联图层，改音频需要复核相关字幕和动作。不能以“只改一个模块”为由保留已失效的时间或报告。完成修改后重新校验并渲染受影响部分，再交付。
